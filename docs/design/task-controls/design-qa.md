# Immersal 任务阶段、中断与删除验证

2026-09-30。根据用户提供的真机截图和确认要求，将匿名“正在处理…”改为具体任务/阶段，并增加中断和删除本机任务的入口。

## 实现与范围

- 当前操作单独关联任务 ID，区分准备扫描图片、检查云端工作区、清空工作区、上传图片、提交建图和登录。上传时显示当前帧数。
- 处理其他扫描时，提示中和固定操作区都显示其场景名称与阶段。当前扫描已有任务时不再错误提示“尚未开始上传”。
- 准备、检查、上传、提交等待均可中断本机操作。已发出的远端请求保留待确认状态，不把中断视为云端请求回滚。
- 任务详情底部和更多菜单可删除；列表支持左滑或长按删除。确认框显示场景名和删除范围。
- 删除仅移除当前账号的本机任务记录；扫描、名称、ZIP、云端图片与地图均保留。已提交的云端建图不会被取消。需要清空工作区时仍走原有独立确认流程。
- 删除成功才退出被删除任务的详情；保存失败保留记录和错误说明。删除其他记录不会中断正在处理的任务。被删除任务的迟到响应和列表查询不能恢复记录或影响新的操作。
