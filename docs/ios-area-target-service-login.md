# iOS Area Target 服务登录与云处理

此功能通过原生 SwiftUI 表单登录自托管 Area Target 服务。Area Target 服务账号与 Immersal 账号分别管理；浏览器的登录 Cookie 不会自动传给 iOS App。

## 使用

1. 安装包含本改动的 iOS Scanner 构建，进入首页的「Area Target 账号与任务」。使用与网页相同的服务用户名和密码登录。
2. 扫描完成后，在扫描预览页进入 Area Target 云处理，确认扫描信息并上传。App 获取服务的处理要求，为上传准备扫描副本，保留原始扫描。
3. 在任务页面查看上传和云端处理进度。上传中断时，先查询云端结果再恢复，避免重复创建任务。App 进入后台时暂停本机操作，回到前台可继续查看任务。
4. 处理完成后点击下载，App 校验结果 ZIP 的大小、SHA-256 和资产内容，再保存到本机。已保存的资产可以通过系统分享导出。
5. 会话过期或被服务撤销后，页面提示重新登录。重新登录后可继续查询保留的任务。退出登录会清除本机该服务的登录会话，并尝试撤销服务端会话。

App 不保存登录密码。登录会话和每个任务的独立凭据保存在本机 Keychain，不启用 iCloud 同步；公开任务日志不包含这些凭据。云请求同时携带服务会话和该任务的凭据。登录请求绑定固定 HTTPS 服务域名，拒绝重定向。

新任务使用 https://at.3dugc.com。历史记录如标记旧服务，会继续使用原服务，并需要在该服务上登录。会话按域名分别保存。

## 常见提示

- 「服务登录尚未配置，请联系管理员」对应服务端 `auth_not_configured`：需要先在部署环境配置服务用户名和密码哈希，并重建容器；iOS 端不能替代服务端配置。
- 「服务登录已失效，请重新登录」：会话过期、退出或凭据修改后重新登录。
- 「无法访问本机登录凭据，请解锁设备后重试」：解锁设备后重试；不会把凭据降级保存到普通文件。
- 任务仍需要本机源扫描时，扫描历史禁止删除该扫描，避免中断后无法恢复。

## develop 发布边界

本次落到 develop，包括原生登录、云处理任务和资产下载所需的最小基础。合并代码不会自动更新手机上已经安装的 App；需要从该分支重新构建并安装。此次不安装手机构建，不推进 main/publish，不更新线上 latest 服务。

验证证据记录在 [develop 实施记录](superpowers/plans/2026-10-05-ios-service-login-develop.md)。模拟器测试和通用设备编译不代表签名真机验收；实际真机登录、扫描上传和下载仍应使用真实扫描做验收。
