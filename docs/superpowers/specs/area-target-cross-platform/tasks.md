## 执行规则

- 顺序依赖见总计划；仅在依赖合同冻结后，并行开发互不重叠的文件。
- 开始任务时保留 `[ ]` 并写进度说明；只用真实命令与设备证据更新 `[x]`。
- 新平台不完整时允许后续研究，但不能把相机能力缺失的设备写为可定位。
- 任何不属于 R01–R13 的功能改动先更新需求/设计，不能借跨平台迁移扩展云服务、算法路线或产品功能。
- 计划任务完成与设备商业验收分开。文档更新、编译通过、模拟器回放和合成线上联调都不替代现场验收。
